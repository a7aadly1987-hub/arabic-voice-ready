# ElevenLabs audio tags with Arabic (v3 / v4 models)

Tags go in square brackets, in English, inline with the Arabic text. They are not read aloud.

| Tag | Use it for | Arabic example |
|---|---|---|
| `[excited]` | hooks, offer reveals | `[excited] الجمعة البِيضاء وصلت!` |
| `[short pause]` | between list items, before a price | `مخدات طبية، [short pause] مقاعد طبية` |
| `[long pause]` | scene change in a long narration | `… [long pause] وبعد سنين` |
| `[warmly]` | brand story, testimonials | `[warmly] إحنا هنا علشانك` |
| `[whispers]` | teasers, secrets | `[whispers] العرض ده لفترة قصيرة` |
| `[laughs]` | casual social content | `[laughs] أيوه بجد!` |

Tips:

- **One emotion tag per 2–3 sentences.** Stacking tags makes the voice unstable.
- **Pauses beat punctuation.** Arabic commas are often ignored; `[short pause]` is reliable.
- **Pick an Arabic-native voice.** Egyptian voices in the library (search “Egyptian”) handle عامية far better than multilingual English voices.
- **Each run gives two takes.** Generate once, keep the better take, fix the words that broke, then regenerate — instead of regenerating blindly.
- **Sync later, not now.** Leave clear pauses between sentences; it makes it easy to find sentence starts and time video scenes to them.
